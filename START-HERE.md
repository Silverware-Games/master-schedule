# Start Here

Silverware Games is an independent creative studio making games, interactive projects, art, media, and tools. The Silverware Drawer keeps the knowledge behind that work understandable and findable.

You do not need to read the whole repository. Choose the path that matches why you are here.

## Community

For players, fans, curious visitors, and people who want to understand what Silverware Games makes and values.

Start with the [Community Hub](docs/community/COMMUNITY-HUB.md).

## Collaborators

Start with the [Collaborator Hub](docs/collaborators/COLLABORATOR-HUB.md).

## Clients

Start with the [Client Hub](docs/clients/CLIENT-HUB.md).

## Internal Team

The [Operational Docs Index](docs/indexes/operational-docs.md) routes maintainers to task-focused workflows. The [Incomplete Docs Index](docs/indexes/incomplete-docs.md) tracks drafts and material awaiting review.

## How The Drawer Stays Useful

- Organize by audience first and task second.
- Treat audience labels as navigation, not access control; everything committed here is public.
- Keep hub pages short; put detailed instructions in workflow documents.
- Prefer one canonical explanation over repeated summaries.
- Mark uncertain material as `Draft` or `Needs Review`.
- Update the repository map whenever a document is added, removed, renamed, or materially repurposed.
- Write useful knowledge down now and improve it over time.
