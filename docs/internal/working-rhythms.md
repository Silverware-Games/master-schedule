# Working Rhythms

Silverware Games works in focused, iterative bursts rather than on a fixed public production calendar. This document sets expectations; it does not create deadlines or output quotas.

## What To Expect

- Work moves among games, art, media, infrastructure, documentation, and client projects.
- Commits and public updates often arrive in clusters.
- A quiet public channel may reflect private development or client work.
- Experiments are allowed to remain experiments; not every prototype must ship.
- Sustainable momentum matters more than maintaining an artificial daily streak.

## Common Modes Of Work

### Game Development

Prototyping, tuning, UI and accessibility work, content creation, refactoring, testing, and releases. A project tracker or issue repository is the best source for concrete current work.

### Art And Content

Drawing, editing, streams, articles, short-form experiments, feedback videos, and conversations. See [Content And Channels](../community/content-and-channels.md) for public destinations.

### Client Work

Scoped design, development, technical consulting, staging, review, and delivery. Client commitments can temporarily take priority over visible studio output.

### Maintenance And Operations

Hosting, telemetry, deployments, documentation, backups, and repository upkeep. This work is less visible but necessary for everything else to remain healthy.

## Collaboration Expectations

- Agree on the task, owner, and definition of done before relying on a deadline.
- Use the relevant issue tracker or repository for concrete status.
- Raise blockers directly; do not interpret silence as a status report.
- Prefer small, reviewable contributions over large unannounced rewrites.
- Treat this page as cultural context, not a substitute for project planning.

## When A Real Date Matters

Record releases, client commitments, meetings, and other date-sensitive work in the calendar or tracker actually used by the responsible people. Link to that source from the relevant project documentation when broader visibility is appropriate.
