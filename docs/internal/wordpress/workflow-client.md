# Silverware Games WordPress Development Process

## Our Guiding Rule

**Your live website is never edited directly.**

All work is done on a safe copy first.  
The live website is only updated after you review and approve the changes.

This ensures your website and data are always protected.

# How the Process Works

Our development process has four simple steps.

## 1 — Safe Website Backup

Before any work begins, a full backup of the website is created.

This backup includes:

- all website pages
- images and media
- themes and plugins
- the WordPress database

This ensures the entire website can always be restored if needed.

## 2 — Create a Safe Working Copy

A private working copy of the website is created on the Silverware Games server.

Example staging address:

https://clientname.silverwaregames.com

This staging site is an exact copy of the real website.

Important:

- the live site remains unchanged
- search engines cannot index the staging site
- work can be done safely without affecting visitors

## 3 — Development and Improvements

All design and development work happens on the staging site.

Typical improvements may include:

- design updates
- layout adjustments
- plugin improvements
- performance optimization
- bug fixes
- content improvements

During this stage the live website continues running normally.

## 4 — Client Review

You will receive a link to preview the updated website on the staging server.

Example:

https://clientname.silverwaregames.com

You can review the site exactly as it will appear when published.

Revisions can be made during this stage until everything looks right.

## 5 — Publish the Approved Version

Once the changes are approved, the updated version is safely transferred to the live website.

Before publishing:

- a fresh backup of the live site is created
- the update process is carefully controlled
- the new version is verified

This ensures a smooth and safe transition.

# Why This Process Is Safe

This workflow protects your website in several ways:

- The live website is never edited directly
- Full backups exist before any work begins
- All development happens on a staging copy
- You review changes before they are published
- Updates can be reversed if necessary

# Summary

Silverware Games uses a staging workflow designed to protect your website while improvements are made.

**Your live website stays online and untouched until you approve the final version.**

This allows development to happen safely, transparently, and without risk to your existing site.
