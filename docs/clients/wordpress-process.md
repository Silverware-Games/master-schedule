# How We Work On WordPress Sites

Silverware Games uses a review-first process intended to keep your live website stable while improvements are prepared.

## The Process

1. **Access and scope:** We agree on the work, approval contact, and minimum access required. Credentials are exchanged privately, never through this repository.
2. **Safe working copy:** When appropriate, we prepare a private staging copy so work can be reviewed away from the live site.
3. **Development and testing:** We implement the agreed changes and test the pages, forms, media, and integrations affected by them.
4. **Your review:** You receive a preview and can request revisions before publication.
5. **Approval and release:** After written approval, we confirm recovery readiness, publish the approved changes, and check the live site.
6. **Handoff:** We notify you when the release is complete and identify any follow-up work.

## What We Protect

- Your live site remains the production source while work is under review.
- Access is limited to what the project requires.
- Backups and rollback are considered before production changes.
- Active production data—such as orders, submissions, and accounts—is not casually replaced with an older staging copy.
- Credentials, site exports, and private client data are not stored in the public Silverware Drawer.

## What We Need From You

- A clear scope and a person authorized to approve the work
- Timely access through a private, secure channel
- Review feedback on the staging or preview version
- Written approval before publication
- Notice of important live-site changes made during development

The exact technical workflow varies by host and site. We will explain any release-specific risk or downtime before asking for approval.
