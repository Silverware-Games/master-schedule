# Repo And Communication Norms

This file defines default collaboration norms for documentation and project coordination.

## Repo Norms

- keep files in audience-appropriate folders
- prefer clear file names over clever names
- keep index pages current when adding docs
- avoid storing operational procedures in `README.md`

## Communication Norms

- be direct and respectful
- propose changes with context
- prefer written decisions for traceability
- document outcomes, not just discussions
