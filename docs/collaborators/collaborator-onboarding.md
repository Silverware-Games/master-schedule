# Collaboration Guide

Welcome! This guide covers everything you need to start contributing to Silverware Games projects.

## Onboarding Flow

New collaborators should complete these steps:

1. **Read [`START-HERE.md`](../../START-HERE.md)** — Understand the repository structure and navigation.
2. **Pick your contribution path** — Choose an area that aligns with your strengths.
3. **Define your first contribution** — Start small and aligned with project priorities.
4. **Confirm working scope** — Align with the team on your initial focus area.

## Contribution Paths

- **Gameplay Design and Iteration** — Refine mechanics, balance, and player experience
- **Engineering and Tooling** — Build systems, tools, and technical infrastructure
- **UI and UX Refinement** — Design interfaces and optimize user flows
- **Art and Animation Support** — Create visual assets and motion design
- **Documentation and Content Operations** — Maintain docs, guides, and communication

## Repo and Communication Norms

These norms keep collaboration smooth and documentation maintainable.

### Repo Norms

- **Keep files in audience-appropriate folders** — Use [`public/`](../public/), [`collaborators/`](./), [`clients/`](../clients/), or [`internal/`](../internal/).
- **Prefer clear file names over clever names** — Optimize for scanning and searchability.
- **Keep index pages current when adding docs** — Update [`repo-map.md`](../indexes/repo-map.md) and other indexes.
- **Avoid storing operational procedures in [`README.md`](../../README.md)** — Root README is for navigation only.

### Communication Norms

- **Be direct and respectful** — Clear, honest feedback moves projects forward.
- **Propose changes with context** — Explain the why, not just the what.
- **Prefer written decisions for traceability** — Document outcomes in the repo.
- **Document outcomes, not just discussions** — Capture what was decided and why.
- **Feedback should offer a path forward** — Don't just say "This feature is bad." say "Here's how to improve this feature..."
