# Wash Towel Fill

<img width="640" alt="Wash Towel Fill" src="https://washtowelfill.io/thumb.png" />

**Posture:** Active client-server web game<br>
**Platform:** Browser / server-backed

Wash Towel Fill is a competitive tower-wars-style car wash game. Players optimize a wash while sending waves of filthy cars to friends and rivals.

## Project Links

- **Play:** [washtowelfill.io](https://washtowelfill.io)
- **Design and public issues:** [wash-towel-fill-issues](https://github.com/Silverware-Games/wash-towel-fill-issues)

## Useful Contributions

- Backend and anti-cheat systems
- Competitive balance and wave design
- UI clarity
- Scalability and asynchronous competition

Gameplay authority lives on the server; proposals should preserve that trust boundary.
