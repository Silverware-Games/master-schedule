# Xanadu Live

<img width="384" alt="Xanadu Live" src="https://silverwaregames.com/assets/images/XANADU_ICON.png" />

**Posture:** Playable prototype and technology exploration<br>
**Platform:** PC prototype

Xanadu Live explores sculptable voxel terrain, spherical terrain clusters, procedural worlds, and the kinds of play that can emerge from unusual world-building technology.

## Project Links

- **Public home and media:** [xanadu.live](https://xanadu.live)
- **Design and public issues:** [xanadu-live-gdd](https://github.com/Silverware-Games/xanadu-live-gdd)
