# Gruboli

<img width="640" alt="Meet the Gruboli" src="https://silverwaregames.com/assets/gruboli/MeetTheGruboli.png" />

**Posture:** Active worldbuilding and transmedia IP<br>
**Format:** Characters, lore, visual development, and future games or media
