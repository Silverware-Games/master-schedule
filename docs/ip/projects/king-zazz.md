# King Zazz's Algorithm

<img width="640" alt="King Zazz's Algorithm" src="https://kingzazz.com/thumb.png" />

**Posture:** Playable web game; actively maintained<br>
**Platform:** Browser

King Zazz's Algorithm is a deterministic pattern-prediction game. Players observe the system, anticipate its next move, and succeed by learning how the algorithm behaves.
