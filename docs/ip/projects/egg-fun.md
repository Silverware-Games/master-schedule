# Egg Fun

<img width="640" alt="Egg Fun" src="https://eggfun.io/thumb.png" />

**Posture:** Playable web game; actively maintained<br>
**Platform:** Browser

Egg Fun is an egg-themed spatial puzzle about sorting and moving eggs among egg-shaped baskets, inspired by classic transport logic puzzles.

## Project Links

- **Play:** [eggfun.io](https://eggfun.io)
- **Design and public issues:** [eggfun-issues](https://github.com/Silverware-Games/eggfun-issues)
