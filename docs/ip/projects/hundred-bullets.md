# Hundred Bullets

<img width="640" alt="Hundred Bullets" src="https://silverwaregames.com/assets/images/HundredBulletsThumb.jpg" />

**Posture:** Released game<br>
**Platform:** Xbox / Windows PC

Hundred Bullets is a puzzle SHMUP in which the central danger is the player's own fire. Deliberate shooting turns reflex action into spatial reasoning and self-created pressure.
