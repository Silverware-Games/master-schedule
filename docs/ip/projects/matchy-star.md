# Matchy Star

<img width="640" alt="Matchy Star" src="https://silverwaregames.com/assets/images/matchy.webp" />

**Posture:** Private alpha<br>
**Platform:** PC / Steam<br>
**Access:** Limited invited testing; not fully released

Matchy Star is a fast puzzle game about expressive matching, chain reactions, arcade flow, and a journey through a colorful universe. It is still in private alpha while its systems, progression, content, and presentation are tested and refined.

## Project Links

- **Public / store page:** [matchystar.com](https://matchystar.com)
- **Design and public issues:** [matchy-star-gdd](https://github.com/Silverware-Games/matchy-star-gdd)
- **Studio project directory:** [IP Hub](../IP-HUB.md)

## Useful Contributions

- Progression and difficulty tuning
- Onboarding and tutorial clarity
- Accessibility and UX
- Game feel, effects, and quality-of-life improvements

Use the public design repository for current work and discussion. Do not describe Matchy Star as released until its project posture is explicitly updated.
