# Matchy Star

<img width="640" alt="Matchy Star" src="https://silverwaregames.com/assets/images/matchy.webp" />

**Posture:** Private alpha<br>
**Platform:** PC / Steam<br>
**Access:** Limited invited testing; not fully released

Matchy Star is a fast puzzle game about expressive matching, chain reactions, arcade flow, and a journey through a colorful universe. It is still in private alpha while its systems, progression, content, and presentation are tested and refined.
