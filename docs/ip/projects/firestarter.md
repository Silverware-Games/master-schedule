# Firestarter

<img width="640" alt="Firestarter" src="https://firestarter.cc/thumb.png" />

**Posture:** Playable web game; actively maintained<br>
**Platform:** Browser

Firestarter is an FLCL-inspired fan game about controlled burn: move too quickly and everything collapses; move too slowly and momentum disappears.
