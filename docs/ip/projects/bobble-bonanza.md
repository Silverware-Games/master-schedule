# Bobble Bonanza

<img width="640" alt="Bobble Bonanza" src="https://bobblebonanza.io/thumb.png" />

**Posture:** Playable web game; actively maintained<br>
**Platform:** Browser

Bobble Bonanza is a digital pachinko game built around physics, spectacle, anticipation, exponential scoring, and joyful randomness.
